# 🚀 AI Workplace Productivity Assistant

A modern, responsive web application designed to help professionals automate daily work tasks using AI. This SaaS-style productivity tool combines intelligent automation with a clean, intuitive interface.

---

## ✨ Overview

**AI Workplace Productivity Assistant** streamlines everyday office workflows such as email writing, meeting documentation, task planning, and research. It integrates structured AI prompt engineering to deliver professional, accurate, and actionable outputs.

---

## 🎯 Core Features

### 📧 Smart Email Generator

- Tone (formal, casual, persuasive, etc.)

## 🧠 Prompt Engineering Approach

Each feature uses structured prompts to ensure consistent and professional outputs:

### Email Prompt Example
```

You are a professional business assistant.
Write an email with the following details:

* Purpose: {purpose}
* Recipient: {audience}
* Tone: {tone}
  Ensure clarity, professionalism, and concise wording.

```

### Meeting Notes Prompt Example
```

Analyze the following meeting notes:
{raw\_text}

Extract:

* Key Points
* Action Items
* Deadlines
* Responsible Parties
  Present in a structured format.

```

### Task Planner Prompt Example
```

Organize the following tasks:
{task\_list}

Prioritize by urgency and importance.
Create a clear schedule with time blocks.

```
